# מה מסתתר בין השורות? — הוראות הפעלה

משחק כתיבה לכיתה ד׳ (מצטיינים ומחוננים): רואים רמזים, מגלים רגשות, כותבים סיפור שאפשר להרגיש.

## איך פותחים
- לחיצה כפולה על **index.html**. המשחק נפתח בדפדפן (Chrome, Edge או Firefox עדכניים).
- הכול נמצא בקובץ אחד: אין צורך באינטרנט, בהרשמה או בהתקנה. אפשר גם להעלות את הקובץ לאתר סטטי.
- מתאים למחשב, למקרן ולטאבלט. אפשר לעבוד לבד, בזוג על מחשב אחד, או להקרין לכיתה.

## איך מתקדמים
1. **מגלים** — חמש סצנות קצרות. בכל סצנה: צופים (אפשר לעצור, להתחיל מחדש ולעבור בין רגעים), כותבים מה הדמות מרגישה ואיזה פרט גרם לכם לחשוב כך, ורק אז לוחצים "מה התכוון המחבר?". אחרי החשיפה: משווים, לוחצים על הרמזים המודגשים בקטע (הסרט מראה את הרגע שלהם), מחליטים אם להשאיר את הפרשנות, ומנסים גרסה שבה פרט אחד השתנה.
2. **יוצרים** — ארבעה שלבים: דמות ומקום (כולל "הכוונה שלי" הפרטית) ← כותבים 3–5 משפטים ← "איך נראה את זה?" לכל משפט: בוחרים פעולות, הבעה, תנוחה, קצב ודיבור, צופים בתצוגה מקדימה ומאשרים "זה מתאים למה שכתבתי" ← בודקים ומשכתבים.
   - משפט שלא בחרתם לו המחשה נשאר בסיפור כקריינות. הבמה לא ממציאה לו תנועה.
   - כפתור **"אתגר: שתי תחושות"** פותח את משימת המתקדמים ושתי דוגמאות לצפייה.
3. **מציגים** — מסך נקי להקרנה. הכיתה מנחשת (אפשר לרשום עד 3 פרשנויות), ורק הכפתור "חשיפת כוונת הכותב" מגלה את הכוונה.
4. **התוצר שלי** — בוחרים כותרת ניטרלית ועד 3 תמונות, ומורידים קובץ Word.

לא חייבים לסיים את חמש הסצנות כדי להגיע לסדנה. אפשר לעבור בכל זמן דרך הלשוניות למעלה.

## נגישות ונוחות
- **🔊 צליל** — השתקה בכל רגע. כל צליל חשוב מופיע גם בכתב על הבמה.
- **🖼 תמונות לפי צעדים** — במקום תנועה רציפה, הסרטים מוצגים כצעדים קבועים (אותם אירועים ואותם רמזים).
- מקלדת: Tab בין הכפתורים. על הבמה: רווח מפעיל או עוצר, החצים עוברים בין רגעים.

## איך שומרים
- העבודה נשמרת **אוטומטית** בדפדפן, במחשב שבו עובדים (בפינה למעלה כתוב "נשמר").
- אם הדפדפן חוסם שמירה, מופיע פס צהוב עם כפתור "הורדת גיבוי". אפשר להמשיך לעבוד, אבל לפני שסוגרים צריך להוריד גיבוי.

## קובץ לכיתה לעומת עותק לכותב
| | קובץ לכיתה | עותק לכותב ולמורה |
|---|---|---|
| שם הקובץ | הסיפור_שלי_לכיתה.docx | הסיפור_שלי_עותק_לכותב.docx |
| הסיפור ותמונות נבחרות | ✓ | ✓ |
| מקום לתשובות הקוראים | ✓ | ✓ |
| הרגש שתכננתם וההסבר | ✗ | ✓ (בעמוד נפרד בסוף) |
| ההמחשות שבחרתם והערות | ✗ | ✓ |
| ניחושי הכיתה | ✗ | ✓ |

את **הקובץ לכיתה** מחלקים לקוראים. את **העותק לכותב** שומרים לכותב ולמורה בלבד. האנימציה עצמה מוצגת רק במשחק.

## איך מעבירים פרויקט למחשב אחר
1. במחשב הראשון: **התוצר שלי ← "הורדת קובץ פרויקט (גיבוי)"**. יורד הקובץ הסיפור_שלי_גיבוי.json.
2. מעבירים את הקובץ (דיסק־און־קי, דוא״ל, תיקייה משותפת).
3. במחשב השני: פותחים את index.html ← **התוצר שלי ← "טעינת קובץ פרויקט"** ← מאשרים.
   הטקסט, ההמחשות, הגרסאות והתשובות חוזרים. אם תבחרו קובץ לא מתאים, תופיע הודעה, והטיוטה הפתוחה לא תיפגע.

> קובץ הפרויקט כולל גם את הכוונה הסודית — הוא מיועד לכותב, לא לחלוקה.

## למורה: מבנה הפרויקט
- `index.html` — המשחק המלא (קובץ יחיד, נבנה מתוך `src/`).
- `src/` — קוד המקור: `engine.js` (מנוע במה ואנימציה), `scenes.js` (הוראות הבמה של 5 הסצנות), `data.js` (תוכן, כוונות ורמזים — מופרדים מהבמה), `workshop.js` (מהדר הוראות הבמה בסדנה), `docx.js` (יצירת Word בלי ספריות חיצוניות), `app.js` (מסכים ושמירה).
- בנייה מחדש אחרי שינוי בקוד: `node build.js`.
- `samples/` — תוצר דוגמה שנוצר דרך כפתורי הייצוא של המשחק.
- `tests/` — בדיקות אוטומטיות ודוח בדיקות (`tests/דוח_בדיקות.md`).
